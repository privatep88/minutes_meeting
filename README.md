# نظام إدارة وتوثيق محاضر الاجتماعات — شركة ساعد للأنظمة المرورية

منظومة إلكترونية متكاملة مخصصة لشركة ساعد للأنظمة المرورية (قسم إدارة المرافق والخدمات العامة) لتحرير، توثيق، أرشفة، ومتابعة محاضر الاجتماعات الرسمية بكفاءة عالية وفق أعلى المعايير الإدارية والمهنية.

---

## 🌟 أبرز مميزات النظام

- **محرر المحاضر الرسمي:** تصميم دقيق ومطابق للنماذج الرسمية المعتمدة مع إمكانية التعديل المباشر والتخصيص الكامل للبنود والتوصيات والمواضيع (المستمرة والجديدة).
- **إدارة الصلاحيات والمستخدمين:** نظام صلاحيات متطور يدعم أدوار متعددة (رئيس الاجتماع، مقرر الاجتماع، والمستخدم العادي ذو صلاحية الاطلاع والمعاينة للمحاضر المعتمدة).
- **التوقيع الإلكتروني المعتمد:** إمكانية إضافة وتوقيع المحاضر رسمياً من قبل أصحاب الصلاحية مع التحقق من اكتمال التواقيع الإلزامية قبل الاعتماد النهائي.
- **سجل وأرشيف المحاضر:** أرشفة ذكية لجميع المحاضر مع تصفية متقدمة حسب الحالة (مسودة، قيد المراجعة، معتمد وموقع) وإمكانية استعراضها والبحث فيها.
- **سجل التكليفات ومتابعة المهام:** متابعة تنفيذ القرارات والتوصيات مع مؤشرات الأداء (KPIs) وحالات الإنجاز (جديد، قيد الإجراء، مكتمل).
- **التصدير والطباعة الاحترافية:**
  - طباعة فورية بتنسيق A4 احترافي ونظيف (بدون عناصر التحكم).
  - تصدير مباشر إلى ملفات **PDF** عالية الجودة ومطابقة للتصميم 100%.
  - تصدير إلى مستندات **Word (.docx)**.
- **التوافق التام مع GitHub Pages:** مبني باستخدام Vite مع دعم المسارات النسبية لضمان التشغيل السلس على استضافات الويب الثابتة دون مشاكل الشاشة البيضاء.

---

## 🛠 التقنيات المستخدمة

- **React 19** & **TypeScript**
- **Tailwind CSS v4** للتنسيق والتصميم الاحترافي
- **Lucide React** للأيقونات الرسمية
- **html2pdf.js** لتصدير ملفات الـ PDF
- **docx** لتوليد ملفات مستندات Word
- **Vite** أداة الحزم والبناء السريعة

---

## 🚀 تشغيل المشروع محلياً

1. استنساخ المستودع:
   ```bash
   git clone <repository-url>
   cd <repository-folder>
   ```

2. تثبيت الحزم والمكتبات:
   ```bash
   npm install
   ```

3. تشغيل خادم التطوير المحلي:
   ```bash
   npm run dev
   ```

4. بناء المشروع للإنتاج والنشر:
   ```bash
   npm run build
   ```
